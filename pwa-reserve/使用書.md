## 2. バックエンドのバージョンと主な仕様（v49）

- **現在のGASバージョン**: v49（受講履歴＋今後の予約を1回で取得。予約者はGoogleログインで自分の履歴を閲覧可）
  - ✅ v49は 2026-07-17 に本番デプロイ済み（Apps Script API経由・URL不変）。再デプロイ手順は「7.」を参照
- **旧**: v46（管理者キャンセル時、Googleログイン予約者のカレンダーから正しく消えるよう改善）
- **フロントの主なバージョン**:
  - v45: 高齢者向けUI簡略化・回数選択削除
  - v45.1: カレンダーをグリッド表示に戻し「日付タップ→大きな時間ボタン」を表示
  - v45.2相当: リフレッシュボタンで「予約確認リスト・時間パネル含め完全リセット」

### 予約まわり
- **複数予約**: 一度に複数枠を予約可能。各枠ごとにイベントを作成または既存イベントに名前を追加。
- **Googleカレンダーへの反映**:
  - 予約者を「回答待ち（needsAction）」でサイレント追加（招待メールは送らない）。
  - 主催者（教室側）を attendees に含めることで、カレンダー上で「全員がこの予定への参加を辞退しました」と誤表示されないようにしている。
  - 複数件予約時は、APIの連続呼び出しを避けるため、2件目以降のゲスト追加前に短い待機を入れ、失敗時は1回リトライする。
- **反映件数の表示**: カレンダー反映が一部のみだった場合、「○件予約しました（Googleカレンダー反映: ○/○件）」と表示する。
- **メール保存（v46）**: Googleログインで予約した場合、イベント説明欄に `email:氏名:メール` を保存（管理者キャンセル時のゲスト削除に使用）。

### 取り消しまわり
- **取り消し**: 選択した予約をまとめて取り消し可能。予約した数と同じ数だけ event_id を送ることで、同じ数だけ確実に削除・ゲスト削除される。
- **カレンダーからの消去**: 生徒のGoogleカレンダーからも予定を消すため、`sendUpdates: 'all'` でGoogle側にキャンセル通知を送信している。
- **締切**: 当日および「前日17:00」を過ぎたキャンセルはバックエンドで拒否。
- **管理者キャンセルとGoogleログイン（v46）**:
  - 管理者がキャンセルする場合、フロントからは「生徒メール」が渡らないため、従来は生徒のカレンダーから消えないケースがあった（特に同一枠に複数名がいる場合）。
  - v46では、説明欄に保存した `email:氏名:メール` を使って該当ゲストを削除するため、生徒側カレンダーが正しく更新される。
  - **注意**: v46適用前に作成された古い予約は、説明欄にメールが保存されていないため、管理者キャンセルで完全に消えない場合がある（新規予約から改善）。

### 予約・キャンセルの締切
- 予約: 明日以降の枠のみ。明日の枠は「本日17:00」まで受付。
- キャンセル: 明日以降の予約のみ。明日の予約は「本日17:00」まで受付。当日・締切後は教室へ直接連絡。

## 3. 管理者向け

### 管理者ダッシュボード
- **入口**: 予約ページ最下部の「管理者の方はこちら」リンク。
- **パスコード**: `2684`（`Code.gs` の `ADMIN_PASSCODE` で変更可能）。
- **表示内容**: 「今日」「明日」の各時間枠の予約者名一覧。

### 受講履歴検索（v45〜）
- **用途**: 管理者が「予約者の名前」で過去の受講履歴を確認する。
- **期間**: 1ヶ月 / 3ヶ月 / 6ヶ月 / 1年（ボタンで選択）
- **表示**: 月ごとにグループ化し、受講日・開始時刻・クラス名（イベントタイトル）を表示
- **注意**: 運用開始直後は、6ヶ月/1年を選んでも過去データが存在しないため同じ件数になることがある。

### 主な設定（Code.gs の CONFIG）
- `TEACHER_EMAIL`: 管理者（講師）への通知先メールアドレス。
- `CALENDAR_ID`: 予約に使うGoogleカレンダー（通常は `'primary'`）。
- `ADMIN_PASSCODE`: 管理者画面のパスコード。

## 7. 予約確認＋受講履歴の同時表示（v49）

### 何ができるようになったか
1回の操作で「予約内容の確認（今後の予約）」と「受講履歴（過去）」が**一緒に**表示されます。

| | 予約・予約確認 | 受講履歴 |
|---|---|---|
| **予約者** | 名前だけでOK（ログイン不要） | **Googleログインが必要**。期間は 1/3/6/12ヶ月ボタンで切替 |
| **管理者** | パスコードでログイン後、名前で検索 | 同じ検索で「今後の予約」と「受講履歴」を両方表示 |

- 予約者：STEP 4「予約を確認する」を1回押す → 予約内容（取消可）＋受講履歴。
- 未ログインの予約者には「受講履歴を見るにはGoogleでログインしてください」と表示（予約・予約確認自体はログイン不要のまま）。
- 管理者：管理者メニューの「受講履歴を検索」1回で両方表示。

### GASの再デプロイ手順（v49は適用済み。今後の更新時の参考）
※ v49 は本番反映済みです。次回 Code.gs を変更したときは以下の手順で反映します。

1. [Google Apps Script](https://script.google.com/) で本プロジェクトを開く
2. `Code.gs` の中身を、リポジトリの `pwa-reserve/gas/Code.gs`（v49）で**全置き換え**
3. 「デプロイ」→「**デプロイを管理**」→ 既存デプロイの**鉛筆（編集）アイコン**をクリック
4. 「バージョン」で「**新バージョン**」を選択 →「デプロイ」
   - ※この手順なら **URLは変わりません**（`main.js` の `API_BASE` 変更は不要）
   - ※もし「新しいデプロイ」を選ぶとURLが変わるため、その場合は `main.js` 1行目と本使用書のURLを更新すること
5. 予約ページで「予約を確認する」を押し、Googleログイン状態で受講履歴が出れば成功

### 補足（セキュリティ）
- 受講履歴はGoogleログイン（メールアドレスの送信）を条件にしています。**画面上は自分の履歴のみ**表示されます（ログイン時は名前欄がGoogleアカウント名で固定されるため）。
- ただしサーバー側でGoogleのIDトークン検証までは行っていないため、APIを直接叩けば他人の名前で照会できる余地は残ります。より厳密にする場合はIDトークン検証の実装が必要です。
- 予約・予約確認は従来どおり名前のみ（ログイン不要）です。
