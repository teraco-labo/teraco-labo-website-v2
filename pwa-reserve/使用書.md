## 2. 生徒さんの使い方
1. **初回だけ**：お名前 →（確認）→ 講座（5つから）→ 曜日（グループ）を登録。次からは聞かれない
2. ホームは「あなたの予約」（入っている予約の一覧）と「予約をとる」ボタンだけ。取り消しのボタンはふだん出さない
3. 「予約をとる」を押すとカレンダー。その月の**自分のクラスの日**が色つきで、最初から全部えらんだ状態。行けない日を押して外し、「この○回を予約する」→ 確認 →「予約できました」。**同じコースの別クラスの日（点線）もえらべる**（例：パソコン応用A↔B。分数は同じ）
4. 個人レッスンの人は、火・木の日を押して時間をえらぶ。グループの人も「個人レッスン（50分）も予約する」から取れる
5. 取り消しは、ホームの「予約を変更する」を押す → 取り消したい予約を押してチェック（複数OK）→「えらんだ○件を取り消す」→ 確認画面で「はい、取り消す」。日時の変更は各予約の「この予約の日時を変える」から。前日17時を過ぎた予約は薄く表示され、選べない（「電話で相談」は混乱のもとなので廃止。困ったときは教室で直接）
6. 右上の「最初から」は、えらびかけを全部消してホーム画面（あなたの予約／予約をとる）に戻る
7. 「受講履歴・そのほか」：Googleログイン（任意）で受講履歴が見られ、予約をGoogleカレンダーにも入れられる

- **講座カレンダーとの連動**: 先生が管理者画面で登録した休みの日は日付マスに「休み」（薄い赤）、体験会などの予定は「体験会」の札で出る。カレンダーの下の「◯月の講座カレンダーを見る」で、印刷用と同じ全体表（火〜金の時間割）が開く

- **月の回数の上限**: 生徒さんの月回数（4回／2回）は Teraco Customer の顧客名簿 `monthlyLessons` から読む（2026-09-25 承認済み。名簿の月回数が空・0の人は「月4回」扱い）。ルールは「となり合う2か月の合計が回数×2まで」（月4回→2か月で8回、月2回→4回）。個人レッスンは数えない。管理者の代理操作は上限なし
- **体験会の予約**: 講座カレンダーに登録した予定のうち、**名前に「体験会」が入っているもの**は生徒さんがえらべる（初めての方も、在籍の方も。在籍の方は有料）。カレンダーの日付に「体験会」の札が出て、押すと時間の一覧に「10:00 体験会スマホ（45分）」のように出る。予約は「スマホ 体験会(45分)」「パソコンAI 体験会(45分)」の名前でカレンダーに入る（名前に「パソコン」があればパソコンAI）。定員8、月の回数には数えない。名前に「体験会」が無い予定（出張など）は選べない
- **翌月の仮予約**: 公開した月の次の月（例：10月を公開したら11月）も、クラスの曜日を仮で選べる。先生が休みの日を登録・公開すると確定。仮の月には「まだ仮です」と表示

## 3. 毎月の作業（先生）
1. 予約アプリの一番下「管理者」→ パスコード →「講座カレンダーを編集する」
2. 月をえらび、**休みにする日・週を押す**。「水曜が5回です…」のように回数を教えてくれる
3. 体験会などがあれば「特別な予定」に足す
4. 「保存する」→「○月の日程を確定して公開する」→ もう一度「保存する」
   - **公開した月だけ、生徒さんが予約できる**。未公開の月は「まだ決まっていません」と出る
5. 「印刷用カレンダーをひらく」→「印刷する／PDFにする」。Numbersで作る必要はない

## 4. 管理者の代理操作
- 「だれの予約を操作しますか？」で名前を打つと、予約カレンダーに出てくる生徒さんが候補に出る
- 選ぶとその生徒さんのホームが開く（上に「代理で操作中」の帯）。過去日・土日・当日も選べ、時間は9〜19時、締切なし
- 「日時を変える」は新しい枠を取ってから古い予約を消す。過去の予約も期間をえらんで一覧・取消できる

- **生徒さんのプルダウン（2026-09-23）**: 管理者画面のいちばん上に、Teraco Customer（てらこ顧客管理DB「顧客名簿」）の在籍・休会の生徒さんが**五十音順**で並ぶ。選ぶだけで代理操作に入れる。一覧にない人（新規など）は下の入力欄に名前を入れる。名簿は10分ごとに読み直す（Customer側で名前を直したら10分待つか、GASのキャッシュが切れるのを待つ）
- 一覧が出ず「authorizeMe を1回実行」と出るとき: Apps Script エディタで `authorizeMe` を実行し、権限を承認する（下記「7.」）

## 5. 仕組み
- 画面：`index.html` + `app.js`、時間割の正本は **`timetable.js`**（コース名・分数・曜日・時間・色。予約アプリと印刷用カレンダーの両方が読む。パソコン応用を90分にするときはここの `min` を変えるだけ）
- サーバー（GAS v50〜、追加分）：
  - `next_data`：空き枠（受講の予約だけを人数に数える。個人レッスンは定員1で、先生に別の予定がある時間は busy）＋自分の予約＋講座カレンダー
  - `schedule_get` / `schedule_set`（管理者）：講座カレンダー。スクリプトプロパティ `SCHEDULE_JSON` に保存
  - 分数はコース名の「(45分)」を優先して決める
  - 予約・取消は従来の `batch_reserve` / `batch_cancel` をそのまま使用
- 予約イベントのタイトルは「スマホ 入門A(45分)」「パソコンAI 応用B(45分)」「スマホ 個人レッスン(50分)」。**先頭の「スマホ 」「パソコンAI 」は他の仕組み（Teraco Customer など）が目印にしているので変えない**
- 振替（同じコースの別クラスへ移る）は `app.js` の `FURIKAE = false` で停止中。`true` にすると生徒側に出る
